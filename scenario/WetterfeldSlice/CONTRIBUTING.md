# Contributing

Contributions to WetterfeldSlice should follow the same process used for the shipped xAquaticRisk scenarios.

1. Base new work on the latest tested model and scenario state.
2. Document any changes to scenario data, metadata, and intended usage.
3. Keep the scenario folder structure stable so existing parameterisations continue to work.
4. Validate the scenario with the current xAquaticRisk version before proposing release.
5. Preserve provenance for derived data copied from the source Muenster scenario.
